## Records to attach when verified

For each unverified item, record the source/creator, rights holder, license or written permission, permitted commercial/editorial uses, attribution requirements, releases for identifiable people, reviewer, date checked, and the location of supporting evidence. Do not infer permission from search results, social posts, file possession, or use in a prior release.

## Dependency license limitation

This review checked the direct client dependency list for likely visual asset packages and verified the Inter font package license. It did not produce a complete legal license report for every transitive npm dependency. Generate and review a complete software license inventory before making a blanket third-party software licensing claim.
