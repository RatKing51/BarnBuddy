# Billing

BarnBuddy supports Free and Premium plans.

## Free

Free is intended for core livestock records and small herds getting started.

## Premium

Premium unlocks advanced reporting, reminders, exports, breeding, finance, and feed planning tools.

## Manage Billing

Open Account Settings to review plan status and billing actions.

## Data After Premium Ends

Losing Premium removes access to Premium tools, but it does not automatically delete finance, feed, inventory, reproduction, or birth records. The records stay saved so they are available again if the account renews Premium.

An administrator can permanently delete the stored Premium records from the user management screen after Premium access has ended. BarnBuddy requires a confirmation before performing this irreversible action.
