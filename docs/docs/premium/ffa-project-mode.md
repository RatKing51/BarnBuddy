# FFA Project Mode

FFA Project Mode is included with BarnBuddy Premium. It uses the same blue BarnBuddy interface as the rest of the dashboard.

## What It Includes

- SAE project setup and school-year details
- Existing BarnBuddy animals linked without duplication
- Starting weight, value, ownership, and record-date snapshots
- Activity journals with skills and reflections
- Project income and expense records
- Printable project summaries for students and advisors

If Premium ends, existing FFA project records remain stored. Access returns when the account renews Premium, unless an administrator intentionally deletes the stored Premium data.
